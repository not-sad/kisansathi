# ⚖️ Nyay AI — Legal Rights Advisor (India)
Built for MICROSOFT PROTEX HACKATHON. An AI assistant explaining Indian laws in plain English and hindi.

## 🛠️ Tech
- HTML/CSS/JS + Google Gemini 3 Flash API.

## 🚀 Setup
1. Add your API Key to `app.js`.
2. Open `index.html` via Live Server.
